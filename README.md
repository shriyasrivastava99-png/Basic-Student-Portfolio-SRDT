# Basic Student Portfolio Website

## Project Description
The Basic Student Portfolio is a simple and beginner-friendly website created using HTML. The main purpose of this project is to introduce myself, showcase my educational background, highlight my skills, and provide important links to my academic documents and professional profiles. This project demonstrates the use of various HTML tags and elements to create a structured and organized personal portfolio.

## Objectives
The objective of this project is to understand the fundamentals of HTML and learn how to build a basic website from scratch. It helps in understanding webpage structure, text formatting, headings, paragraphs, lists, tables, hyperlinks, images, and other essential HTML elements.

## Features
- Introduction and personal information section.
- Educational background and academic details.
- Technical skills and areas of interest.
- Links to academic documents and mark sheets.
- Contact information and professional profile links.
- Navigation between different sections of the portfolio.

## Technologies Used
**HTML5:** Used to structure the website, organize content, create different sections, add hyperlinks, and display information in a readable format.

## Learning Outcomes
Through this project, I gained practical experience in writing HTML code and using different HTML tags to create a functional and well-organized webpage. I learned how to structure content, connect webpages using hyperlinks, organize information using lists and tables, and create a basic personal portfolio suitable for academic purposes.

## How to Run the Project
1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code or any code editor.
3. Locate the `index.html` file.
4. Open the file in any web browser to view the portfolio.

## Conclusion
This project represents my initial step toward web development. It helped me strengthen my understanding of HTML fundamentals and apply classroom concepts in a practical assignment. The portfolio can be enhanced in the future by adding CSS for styling and JavaScript for interactive features.
